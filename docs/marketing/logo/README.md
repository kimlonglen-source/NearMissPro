# NearMissPro logo kit

The same shield-and-check mark used in the app, exported for reuse.

| File | Use it for |
|---|---|
| `logo-icon.svg` | Master vector icon — scales to any size, no font needed. Use this for print or when a designer needs the source. |
| `logo-icon.png` | Transparent shield only (1024px) — watermarks, tight spaces. |
| `logo-horizontal.png` | Shield + "NearMiss Pro" wordmark, transparent — website headers, email signatures, letterheads. |
| `logo-stacked.png` | Shield above wordmark, transparent — square-ish spaces, slides. |
| `logo-app-icon.png` | White shield on teal rounded square — **LinkedIn profile picture, favicon, app icon.** Reads well tiny. |
| `logo-app-icon-light.png` | Teal shield on white rounded square — for dark backgrounds or print. |

Brand: teal `#0F6E56`, wordmark "NearMiss" teal + "Pro" near-black `#1A1A2E`, font Inter ExtraBold.
