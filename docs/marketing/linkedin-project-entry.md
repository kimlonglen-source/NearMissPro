## Project name
NearMissPro

## Description
NearMissPro is a near-miss reporting and continuous-improvement tool I'm building for New Zealand community pharmacies.

Pharmacies catch dispensing near misses every day — the wrong strength, a look-alike drug, a mistyped direction. But most of that learning is lost by review time: it sits in a logbook no one has time to interpret, so the same near misses keep coming back.

NearMissPro closes that gap:

• Staff log a near miss in seconds — anonymous, no patient details, just a few taps
• It surfaces the patterns that keep repeating and flags high-risk medicines (insulin, anticoagulants, opioids)
• At review time it generates a plain-English, meeting-ready report — and shows whether last month's changes actually reduced the near misses
• AI suggests practical, NZ-best-practice fixes, but every decision stays with the pharmacist — and AI can be switched off entirely

Privacy-first by design: no patient-identifying information is collected, near misses are anonymous to the team, and it's built around the NZ frameworks that apply — the Privacy Act 2020, the Health Information Privacy Code, and the Pharmacy Council's continuous-quality-improvement expectation.

The whole loop: log it, review it, learn from it — no blame, no names.

Status: in development, with free early access opening to NZ pharmacies.
